# Balanza

手機用的個人資產負債統計 App（PWA），可加到主畫面像原生 App 一樣使用。

**開啟：** https://bruce-hsieh.github.io/Balanza/

## 功能

- **小秤吉祥物與等級**：依淨資產分成 11 個等級（Lv.6 傳說富豪 ～ Lv.-5 債務深淵），每級有不同造型與動畫；「等級」分頁可看所有型態、門檻與升級進度
- **股票持股**：台股（上市、上櫃、ETF）與美股輸入代號和股數，自動帶出最新收盤價、漲跌、損益，點開可看近 30 日走勢小圖
- **資產分組**：同類別資產聚集成大項，顯示小計與占比，可展開看細項
- **自繪可愛圖示**：所有圖示都是 `icons.js` 內的自繪 SVG
- **總覽**：淨資產、總資產、總負債、負債比、每月還款、加權平均利率、每月利息與還本金
- **寬限期提醒**：列出仍在寬限期的貸款、結束年月，以及結束後月付會增加多少
- **負債來源**：依銀行（含銀行代碼）加總剩餘本金與月付
- **貸款自動試算**：輸入貸款金額、利率、年限、撥款年月、寬限期、還款方式（本息平均／本金平均／只繳息），自動算出目前月付、剩餘本金、已繳期數、還清年月與剩餘利息
- **實價登錄估價**：輸入地址自動對應縣市／行政區／路段，以近兩年成交單價中位數（已扣車位）× 坪數估算房屋價值，並列出最近成交
- **車輛**：選廠牌（可愛小車圖示）、輸入購入年份與價格估算殘值
- **所有選單都有小圖**：底部彈出式選擇器，銀行可用代碼或名稱搜尋
- **備份**：匯出／匯入 JSON；支援 TWD / USD / JPY / EUR
- 離線可用、深色模式、動畫（減少動態效果設定下會自動關閉）

## 實價登錄資料

`.github/workflows/lvr.yml` 每週一自動執行 `scripts/build_lvr.py`：從內政部實價登錄開放資料下載近 8 季「不動產買賣」，排除親友間、特殊關係等交易，彙整成 `data/lvr/<縣市代碼>.json` 並提交。
也可在 GitHub 的 **Actions → 更新實價登錄資料 → Run workflow** 手動更新。

查詢時 App 下載的是整個縣市的公開彙整檔，地址只在手機上比對，不會送出。

## 股價資料

`.github/workflows/stocks.yml` 在台股收盤後（14:23）與美股收盤後（05:41）執行 `scripts/build_stocks.py`：
台股取自證交所與櫃買中心每日收盤行情；美股（S&P 500＋熱門個股／ETF）與匯率取自 Yahoo Finance 日線。
清單外的美股可加到 `data/stocks/extra.txt`（repo 公開，寫入的代號別人看得到）。

## 安裝到手機

- **iPhone（Safari）**：開啟網址 → 分享 → 加入主畫面
- **Android（Chrome）**：開啟網址 → 選單 → 安裝應用程式／加到主畫面

## 資料隱私

本 repo 是公開的，但**你的財務資料不會進 repo**——資料只存在手機瀏覽器的 localStorage。
換手機或清除瀏覽器資料前，請到「設定 → 匯出 JSON」備份。

## 更新

推送到 `main` 後 GitHub Pages 會在 1～2 分鐘內重新部署。App 採網路優先策略，下次開啟時自動載入新版（版本號顯示在標題旁，修改時請一併更新 `app.js` 的 `APP_VERSION`）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面結構 |
| `style.css` | 樣式（含深色模式） |
| `app.js` | 資料、表單、畫面 |
| `ui.js` | 選擇器、小圖、吉祥物、動畫 |
| `loan.js` | 貸款攤還與寬限期計算 |
| `lvr.js` | 實價登錄查詢與估價 |
| `stocks.js` | 股價讀取與匯率換算 |
| `icons.js` | 自繪可愛圖示庫 |
| `data/catalog.js` | 銀行代碼、車廠、類別等選單資料 |
| `scripts/build_lvr.py` | 實價登錄資料下載與彙整 |
| `scripts/build_stocks.py` | 台股／美股收盤價與匯率下載 |
| `sw.js` | Service Worker（離線與更新） |
| `manifest.json` / `icon*` | PWA 設定與圖示 |
